# Student Task Manager - Project Documentation

## 1. What the Project Is
A responsive web application built from scratch to help students manage, search, and track their daily academic tasks.

## 2. Features Implemented
- Create and display new tasks.
- Mark tasks as completed or pending with live counter updates.
- Delete individual tasks.
- Case-insensitive search filter.
- Clean and responsive CSS layout.

## 3. How to Run It
Open `index.html` directly in any web browser (Chrome, Firefox, etc.).

## 4. AI Usage
- Used Gemini/ChatGPT to learn step-by-step implementation, structure HTML/CSS/JS, and understand debugging techniques.
