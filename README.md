# Student Task Manager

A warm paper-themed Student Task Manager - frontend only, localStorage for persistence.

## Features
- Add, toggle complete, delete tasks
- Single tasks array as source of truth
- Tolerant localStorage read/write (handles corrupted data)
- Search and filters
- Persists across reload
- Responsive 320px / 375px
- Works 100% local - no backend

## Project Structure
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## How to Run
Open index.html in browser.
